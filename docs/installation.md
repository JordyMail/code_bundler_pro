# Panduan Instalasi Lengkap

## Windows

### Metode 1: Python dari Official (Rekomendasi)

1. **Download Python 3.8+**
   - Kunjungi [python.org/downloads](https://python.org/downloads)
   - Download installer untuk Windows
   - **CENTANG** "Add Python to PATH" saat instalasi

2. **Verifikasi Instalasi**
   ```cmd
   python --version
   ```
3. **Clone Repository**

```cmd
git clone https://github.com/username/AI-Code-Bundler-Pro.git
cd AI-Code-Bundler-Pro
```

4. **Install Dependensi**
```cmd
pip install -r requirements.txt

```

5. **Jalankan Aplikasi**
```cmd
python src/code_bundler_pro.py
```
